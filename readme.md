# Discord Notify Bot

Это Discord бот для напоминалок. Вместо того чтобы сделать обычный сервис напоминалок, я решил засунуть его в Discord бота. Работает он за счет Discord API и Mistral AI REST API

У бота есть 3 команды: `/add-task`, `/delete-task` и `/show-task`, для добавления задачи, удаления задачи, и показа списка задач соответственно. `/add-task` и `/delete-task` вызывают modal окна, где можно будет ввести все необходимые параметры, а после чего бот в сообщении, доступном только человеку, вызвавшему команду, выдаст сообщение об успехе. `/show-task` в свою очередь сразу выводит список всех задач пользователя, который вызвал команду в сообщении, доступном только ему. Параллельно фоном бот каждые 10 секунд проверяет, не наступил ли момент, когда надо оповестить пользователя. Когда наступило время - он отправит напоминание в личные сообщения.

# Установка

Для установки необходимо прописать команду

```
go get github.com/sunixssu/DiscordNotificationBot
```

# Использование

Для начала нужно будет создать бота на [сайте Discord](https://discord.com/developers/applications).

Чтобы использовать бота, необходимо создать файл data.env, в котором нужно указать **CLIENT_ID, DATABASE_CONNECTION, BOT_TOKEN, AI_API_KEY, BASE_URL**.

**CLIENT_ID** - это ID сервера, на котором находится бот. Его можно скачать нажав ПКМ по серверу и нажать "Копировать ID". Для этого должен быть включен режим разработчика, который включается в настройках
**DATABASE_CONNECTION** - это ссылка на подключение к базе данных
**BOT_TOKEN** - это токен бота, который можно получить, создав бота на этом сайте. В разделе "Бот" его можно будет найти и скопировать
**AI_API_KEY** - это api-ключ для ИИ, который будет генерировать наиболее подходящее название каналов. Я использовал mistral.ai
После создания бота и добавления его на сервер, запускаем программу
**BASE_URL** - это базовая ссылка для ИИ, который будет использован

После создания бота и добавления его на сервер, запускаем программу
```
go run main.go
```
Если в терминале увидели команду Bot is ready!, то все работает, и ботом можно пользоваться!
